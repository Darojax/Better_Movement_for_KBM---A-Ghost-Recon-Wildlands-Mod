BETTER MOVEMENT FOR KBM v2.0.1
==============================

Better Movement for KBM adds smooth, granular movement-speed control for
mouse-and-keyboard players in Ghost Recon Wildlands. Scroll the mouse wheel
to move between very slow walking and full jogging speed, whether moving or
standing still.

The mod also adjusts standing and crouched Aim-Down-Sight movement to better
match normal movement. The game's normal Walk/Jog binding remains available,
and sprinting restores full jogging speed.

COMPATIBILITY
-------------

Ghost Recon Wildlands game version 133.1.0.9840374
Steam build 24669148

This release supports only the current EAC-free game build. The ASI verifies
the exact game instructions before making any changes. An unsupported or
modified executable is left untouched.

INSTALLATION
------------

1. Exit Ghost Recon Wildlands.
2. Open the game folder containing GRW.exe.
3. Copy winmm.dll and BetterMovementForKBM.asi into that folder, beside GRW.exe.
4. Launch the game normally through Steam or Ubisoft Connect.

No launcher, configuration file, firewall rule, or SayNoToEAC installation is
required.

CONTROLS
--------

- Scroll the mouse wheel to adjust movement speed. Changes made while standing
  still apply when movement begins.
- Use the Walk/Jog key configured inside Ghost Recon Wildlands to jump to the
  opposite vanilla movement range.
- Sprint normally to return to full jogging speed.
- Mouse-wheel speed control remains available while aiming.

The mod uses mouse-wheel input while the game is focused. In Settings > Key
Mapping > Player Combat, reassign "Next Weapon" and "Previous Weapon" from
Mouse Wheel Up and Mouse Wheel Down. Number keys 1, 2, and 3 remain available
for direct weapon selection.

UNINSTALLATION
--------------

Exit the game, then delete BetterMovementForKBM.asi and winmm.dll from the game
folder. If another mod also uses that copy of winmm.dll as its ASI loader, keep
winmm.dll and remove only BetterMovementForKBM.asi.
