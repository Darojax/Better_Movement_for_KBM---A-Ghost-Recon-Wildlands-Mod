[heading][color=#93c47d]Better Movement for KBM[/color][/heading]

Better Movement for KBM gives mouse-and-keyboard players smooth, granular movement-speed control in Ghost Recon Wildlands—similar to the analogue movement available with a gamepad.

Scroll the mouse wheel to transition naturally between a very slow walk and full jogging speed. Selections made while standing still apply when movement begins. Aim-Down-Sight and crouched movement speeds are also adjusted to feel more consistent with normal movement.

Version 2.0.1 is a lightweight native ASI mod. It requires no launcher, configuration file, .NET runtime, firewall rules, or SayNoToEAC installation.

[heading][color=#93c47d]Requirements[/color][/heading]

[list]
[*]A legitimate Steam or Ubisoft Connect copy of Ghost Recon Wildlands.[/*]
[*]Windows 10 or 11 x64.[/*]
[*]The currently supported Ghost Recon Wildlands executable.[/*]
[/list]

The required x64 Ultimate ASI Loader is included as [b]winmm.dll[/b].

[heading][color=#93c47d]Installation[/color][/heading]

[list=1]
[*]Exit Ghost Recon Wildlands.[/*]
[*]Open the game installation folder containing [b]GRW.exe[/b].[/*]
[*]Extract [b]BetterMovementForKBM.asi[/b] and [b]winmm.dll[/b] into that folder, beside GRW.exe.[/*]
[*]Launch the game normally through Steam or Ubisoft Connect.[/*]
[/list]

The mod loads automatically with the game. [b]Do not use the legacy Launcher Edition and the ASI Edition simultaneously.[/b]

[heading][color=#93c47d]Controls[/color][/heading]

Before playing, open [b]Settings → Key Mapping → Player Combat[/b] and reassign [b]Next Weapon[/b] and [b]Previous Weapon[/b] away from Mouse Wheel Up and Mouse Wheel Down. Keys 1, 2, and 3 remain available for direct weapon selection.

[list]
[*][b]Mouse wheel:[/b] Adjust movement speed while moving or select the next speed while standing still.[/*]
[*][b]Your configured Walk/Jog key:[/b] Switch immediately to the opposite vanilla movement range.[/*]
[*][b]Sprint:[/b] Sprint normally; releasing it restores full jogging speed.[/*]
[*][b]Mouse wheel while aiming:[/b] Continue adjusting the underlying movement speed.[/*]
[/list]

The mod automatically uses the Walk/Jog key configured inside Ghost Recon Wildlands. It is not hardcoded to X.

[heading][color=#93c47d]Compatibility[/color][/heading]

[list]
[*]Ghost Recon Wildlands version [b]133.1.0.9840374[/b].[/*]
[*]Steam build [b]24669148[/b].[/*]
[*]Current Steam and Ubisoft Connect installations using the compatible executable.[/*]

Before applying any modification, the ASI verifies the exact game instructions it expects to find. Unsupported or modified executables are left untouched.

[heading][color=#93c47d]Usage and safety[/color][/heading]

Better Movement for KBM is intended and tested for single-player use. Back up important saves before using any game modification.

The ASI modifies movement instructions inside the running game process. This is normal for this type of mod, but unofficial modifications are always used at the player’s own risk. The mod does not install a background service or remain active after the game closes.

[heading][color=#93c47d]Uninstallation[/color][/heading]

Exit Ghost Recon Wildlands, then remove [b]BetterMovementForKBM.asi[/b] and [b]winmm.dll[/b]. If another mod uses the same ASI loader, keep winmm.dll and remove only the ASI.
